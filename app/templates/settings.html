Klucz LLM (szacowanie posiłków)

Wystarczy jeden z kluczy. Aktywny backend: {% if backend %}{{ backend }}{% else %}brak — posiłki trafiają do kolejki{% endif %}

Puste pole = bez zmian. Po zapisaniu klucza aplikacja od razu przetworzy zaległe posiłki z kolejki.

Jak zdobyć klucz

  1. Gemini (za darmo): wejdź na aistudio.google.com, zaloguj się prywatnym kontem Google → „Get API key" → „Create API key" → skopiuj i wklej powyżej. Darmowy limit w zupełności wystarcza na kilka posiłków dziennie.
  2. Claude (płatny): załóż konto na platform.claude.com, doładuj saldo (od ~$5), w zakładce „API Keys" utwórz klucz. Koszt: ~1–3 gr za zdjęcie.

Przenoszenie danych między urządzeniami

Wersja na telefon: mariuszwojciechowski.github.io/bilans-kcal

Otwórz ten adres w przeglądarce telefonu i dodaj do ekranu głównego (Chrome → ⋮ → „Dodaj do ekranu głównego") — bez instalacji, działa na służbowych komórkach. Pełne funkcje: szacowanie Gemini, makro, bilans (szacunkowy — bez Garmina), kolejka offline. Dane zostają w telefonie; każde urządzenie (np. domowników) ma własne, niezależne dane. Wymaga włączenia GitHub Pages w repo (Settings → Pages → main, /docs).
